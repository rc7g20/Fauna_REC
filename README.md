# 遺址獸骨紀錄工具（內部測試版）

> **本儲存庫為研究團隊的內部測試工具，僅供受邀的測試人員使用。**
> 若您不是受邀的測試人員，請勿使用、複製或散布本工具及其內容。

在發掘現場或整理室，逐件記錄獸骨標本的工具。用平板、手機或電腦開啟網頁即可使用，記錄完再把多位記錄者的資料合併，匯出成 CSV 與 JSON。

- **離線可用**：第一次連網開啟後，可以「加到主畫面」安裝。之後沒有網路也能記錄。
- **資料存在自己的裝置**：紀錄和照片存在這台裝置的瀏覽器中，不會上傳到任何地方。請定期匯出備份。
- **多人記錄、最後合併**：每位記錄者有自己的流水號開頭（例如 `AB00001`）。合併時，重複的流水號會自動改號，並留下變更紀錄。
- **防呆**：會依物種與骨骼部位，只顯示適用的欄位。缺少必要資料時無法儲存；可疑的內容（例如測量值和保存區位不符）會在儲存前提醒。

## 功能

| 分頁 | 內容 |
|---|---|
| 記錄 | 出土脈絡、辨識（TaiCOL 物種名冊）、骨骼部位、保存區位（zone 1–8，可在 3D 模型上點選）、癒合、牙齒萌發與磨耗、測量、表面痕跡、病理、照片、數量與重量 |
| 紀錄清單 | 搜尋、修改已儲存的紀錄；可只看「待查核」的紀錄 |
| 匯出與合併 | 匯出 CSV（Excel 可開）、匯出紀錄（JSON）、自動備份到資料夾（電腦）、匯入備份、合併多位記錄者 |
| 設定 | 記錄者與遺址名稱、出土脈絡欄位、自訂測量項目、新增的分類單元、版本與離線檔案 |

## 安裝與開啟

開啟本儲存庫的 GitHub Pages 網址（由計畫負責人提供）。

| 裝置 | 安裝方式 |
|---|---|
| Android 平板、手機（Chrome） | 選單 →「加到主畫面」或「安裝應用程式」 |
| iPad、iPhone（Safari） | 分享按鈕 →「加入主畫面」 |
| 電腦（Chrome／Edge） | 網址列右側的「安裝」圖示 |

- **第一次開啟必須連網**，工具會把程式、物種名冊、參考圖與 3D 模型下載到裝置上，約需 60 MB，建議使用 Wi-Fi。
- **更新**：有新版本時，連網開啟後畫面上方會出現「有新版本可以使用」，按「更新」即可。更新前請先儲存正在填寫的這一筆。
- **讀不到物種名冊、參考圖或 3D 模型時**：到「設定」→「版本與離線檔案」查看哪一項打了 ✗，再按「重新下載離線檔案」。這個按鈕只會清除離線用的檔案副本，**紀錄、照片和設定不會被刪除**。

## 第一次使用

1. **記錄者**：輸入名字。工具會給一個兩個英文字母的代碼，這位記錄者的流水號都用它開頭。同一台裝置可以有多位記錄者，從畫面上方「切換／新增」切換。
2. **遺址名稱**：例如輸入「石橋」，標題會顯示「石橋遺址獸骨紀錄」。每筆紀錄都會存遺址名稱。
3. **出土脈絡欄位**：勾選這批材料需要的欄位（例如發掘區、坑號、層位），也可以新增自訂欄位。標示「必填」的欄位空白時無法儲存。

## 記錄一筆標本

畫面右側會顯示本筆的流水號、編碼摘要，以及最近的紀錄（點選可以修改）。

| 區塊 | 說明 |
|---|---|
| 出土脈絡 | 輸入時會提示這台裝置用過的寫法。按「儲存並保留脈絡」，下一筆會沿用同樣的脈絡。 |
| 辨識 | 在「分類查詢」輸入中文名、學名或英文俗名（例如「豬」「Sus」「sika deer」），選定後會自動帶入上層分類。也可以直接在綱、目、科、屬、種各欄輸入。不確定時勾「疑似 cf.」。只辨識到哺乳綱時要判斷體型。名冊中沒有的分類組合，儲存時會詢問是否新增。 |
| 骨骼部位 | 輸入中文或英文，從選單選擇。只會列出適用於這個物種的部位。<br>・**新增部位**：輸入清單中沒有的名稱時，會詢問是否新增。新增後這筆紀錄會自動標記「待查核」。<br>・**第幾掌骨／蹠骨**：豬科與食肉目選了掌骨、蹠骨或掌蹠骨時必填（豬：2–5；食肉目掌骨：1–5、蹠骨：2–5；無法判斷選「不明」）。8 個區位都保存時不能選「不明」。<br>・**頭骨**：可以勾選可辨識的骨塊（只能選彼此相連的）。勾枕骨可記錄 zone，勾上顎骨可記錄牙齒。 |
| 保存部位與癒合 | 勾選保存的 zone（Serjeantson 1996），按「分區圖」可看參考圖。有 3D 模型的物種和部位，可以直接在模型上點選。只有肢骨、肩胛骨、指（趾）節骨需要記錄癒合；保存的區位包含近端（或遠端）時，才會出現該端的癒合欄位。 |
| 牙齒 | 下顎骨、頭骨（上顎）勾「帶齒」，或選擇游離齒，再勾選齒位，記錄萌發與磨耗（豬用 Lemoine et al. 2014，鹿科用 Bowen et al. 2016）、牙結石、LEH 與牙齒測量。有犬齒時可判斷性別。 |
| 測量 | 依 von den Driesch（1976）代碼，單位 mm，自動整理到小數點後兩位。破損而只能量到最小值時勾「+」。和保存區位不符的項目會以淡色顯示，仍可填寫，但儲存前會提醒。可以按「＋ 新增項目」加入自訂代碼。 |
| 表面痕跡 | 燒炙（範圍、顏色）、切砍痕（切、砍、鑽、鋸）、啃咬痕（食肉類、囓齒類、不明），各自可勾「疑似 cf.」。有 zone 的部位，痕跡位置要從已保存的 zone 中選，也可以在 3D 模型上標示。 |
| 其他 | 病理觀察（**有填寫時必須拍照**，或勾「另有照片（其他相機）」）、可拼合的流水號、照片、待查核與查核說明、備註。 |
| 數量 | 預設 Qty 為 1。碎片可以填 `100+`、`~300` 這類估計值。有測量值的紀錄 Qty 必須是 1。 |

- **儲存**：按「儲存並保留脈絡」（Ctrl+Enter）或「儲存（不保留脈絡）」。紅字錯誤必須修正才能儲存；黃色提醒確認後可以照樣儲存。
- **自動存檔**：每一筆開始時、每 5 分鐘，以及 App 切到背景時，正在填寫的內容會自動暫存。意外關閉後重新開啟，會詢問是否恢復。

### 3D 模型點選

有 3D 模型的物種與部位，「保存部位與癒合」下方會出現模型：

- 單指拖曳旋轉，雙指縮放，點一下區塊就選取或取消該 zone，和上方的 zone 勾選同步。
- 圖層可以切換「保存部位」「切砍痕」（紅色）「啃咬痕」（藍色）。
- 沒有該物種的模型時，會依序借用同屬、同科，或共用設定中指定的物種模型，並在畫面上註明。
- 右側的標本會以左側模型的鏡像顯示。

## 修改與查核

- 點選右側「最近紀錄」，或在「紀錄清單」中點選紀錄，就能修改。儲存後會覆蓋原紀錄。
- 需要之後再確認的紀錄請勾「待查核」，並寫查核說明。待查核的紀錄在列表中以＊和黃色標示，「紀錄清單」可以只顯示這些紀錄。

## 匯出、備份與合併

### 匯出

| 按鈕 | 內容 | 用途 |
|---|---|---|
| 匯出 CSV（Excel 可開） | `紀錄.csv`（一筆一列）、`測量長表.csv`（一個測量值一列）、`牙齒長表.csv`（一顆牙一列）、「照片」資料夾，以及「BAFFA用」資料夾 | 整理與分析 |
| 匯出紀錄（JSON） | 這台裝置的全部紀錄。有照片時是 .zip（內含 JSON 與照片），沒有照片時是 .json | 備份、換裝置繼續記錄、合併 |

在平板上匯出時，可以選「分享」，直接存到雲端硬碟，或傳到 LINE、Email。

### 備份

- **電腦（Chrome／Edge）**：在「自動備份」選一個備份資料夾（建議是隨身碟或雲端同步資料夾）。之後每次儲存都會自動寫入 `獸骨紀錄_自動備份.json`，並每天另存一份。自動備份不含照片。
- **平板、手機**：無法自動寫入資料夾，請**定期按「匯出紀錄（JSON）」並分享到雲端硬碟**。累積 30 筆沒有備份時，畫面上方會提醒。

> ⚠ 紀錄存在瀏覽器中。清除瀏覽器資料、解除安裝 App，或使用私密瀏覽模式時，紀錄會消失。

### 換裝置繼續記錄

在新裝置開啟工具，到「匯入備份到這台裝置」選擇自己的 .json 或 .zip。同一筆紀錄以較新的版本為準，流水號會接續下去。

### 合併多位記錄者

1. 每位記錄者按「匯出紀錄（JSON）」，把檔案交給負責整理的人。
2. 在「合併多位記錄者」一次選擇全部檔案，按「合併並匯出」。
3. 輸出的檔案包含：
   - 三個 CSV（紀錄、測量長表、牙齒長表）
   - `合併後完整資料.json`
   - `流水號變更紀錄.csv`
   - 「照片」資料夾（照片依新的流水號命名）

   - 「BAFFA用」資料夾（見下一節）

流水號重複時會自動改號，並列在 `流水號變更紀錄.csv`。每筆紀錄都保留記錄者的名字。

### 用 BAFFA 分析

BAFFA（獸骨資料分析工具）是依舊的單一試算表格式設計的，不能直接讀本工具的 JSON 或三個 CSV。所以「匯出 CSV」和「合併並匯出」都會另外產生「BAFFA用」資料夾：

| 檔案 | 內容 |
|---|---|
| `遺址名稱_ALL.csv` | 主表，一筆一列，欄名符合 BAFFA：物種、骨骼、數量、側、1–8（區位）、切割、燒炙、啃咬、性別、備註、綱目科屬，以及出土脈絡欄位 |
| `物種_長表_mandible.csv`、`…_tooth.csv`、`…_maxilla.csv` | 牙齒萌發與磨耗、臼齒測量（GL、WA、WP、WM），BAFFA 的「年齡」與「臼齒測量」頁使用 |
| `磨耗對照.csv` | 豬牙萌發階段 0–6 的精確 Lemoine 分數 |
| `說明.txt` | 使用步驟 |

使用方式：把 `_ALL.csv` 和長表放進 BAFFA 的遺址資料夾（平板則一起選取）；`磨耗對照.csv` 放進該遺址的「分析結果」資料夾。

- **物種**是辨識到的最低階層。只辨識到綱的哺乳類寫成「哺乳綱（中型 size）」這類體型分級；無法辨識寫成 UN。
- **性別**只來自犬齒，備註中會寫「犬齒判定性別」，BAFFA 會自動採計。
- 新增的骨骼部位 BAFFA 不認得，第一次載入時會請你歸入既有部位。
- 骨骼測量值（GL、Bp…）BAFFA 不分析，請使用 `測量長表.csv`。

## 圖片與資料來源

工具中的參考圖（測量位置、zone 分區、牙齒萌發與磨耗計分等）取自下列已出版的文獻，**版權屬於原作者與出版者**。這些圖僅為內部研究記錄時對照使用，不得另行擷取、轉載或散布：

- von den Driesch, A. 1976. *A Guide to the Measurement of Animal Bones from Archaeological Sites.*
- Serjeantson, D. 1996.（哺乳類與鳥類骨骼 zone 分區）
- Grant, A. 1982.（牙齒磨耗階段）
- Lemoine, X. et al. 2014.（豬牙齒萌發與磨耗計分）
- Bowen, F. et al. 2016.（鹿科牙齒磨耗階段）

物種名稱資料來自「臺灣物種名錄」（TaiCOL），依其授權條款使用。
